🚀 lokal-ai v1
lokal-ai v1 adalah asisten otomatisasi berbasis terminal Python cerdas yang dirancang khusus untuk memberikan kontrol penuh, cepat, dan efisien terhadap sistem operasi Windows, manajemen file lintas perangkat (termasuk perangkat seluler via MTP), serta otomatisasi alur kerja Trading.

✨ Fitur & Skill Utama
Multi-Disk & MTP Deep-Scan (Paralel): Memindai dan menemukan file atau folder secara super cepat dan simultan di seluruh disk internal (C:\, D:\), flashdisk eksternal, hingga menembus perangkat HP Android terhubung (seperti POCO X3 Pro) tanpa hambatan protokol virtual.

Smart Voice Command (Mode Suara): Dilengkapi fitur Speech-to-Text interaktif yang memungkinkan Anda mengendalikan asisten secara lisan layaknya Jarvis, lengkap dengan frasa pemutus mutlak ("matikan mode suara") untuk kembali ke mode teks secara instan.

TradingView & Gemini Automation: Otomasi tingkat lanjut untuk membuka TradingView Desktop, memaksimalkan layar, mengambil screenshot chart live, menyalinnya ke clipboard, dan langsung mengirimkan prompt analisis teknikal ke Gemini AI secara otomatis.

Presisi Tab Switcher & Browser Control: Manajemen perpindahan tab browser populer (YouTube, Facebook, Instagram, dll.) secara akurat tanpa membuka tab duplikat atau salah ketik query pencarian.

Full Windows & App Control: Mampu mendeteksi dan meluncurkan berbagai aplikasi yang terinstal di laptop (seperti WinRAR, Steam, Zoom, dll.), membuka direktori sistem, mengeksekusi pintasan keyboard (shortcut) Windows secara presisi, hingga melakukan pencarian web umum.
